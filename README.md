# jQuery Assignment #6 (Selectors, Effects, Animations)

**Student:** Arailym Amangeldi

**Group:** SE-2528

## Description

A multi-page website that demonstrates jQuery basics: selectors, effects,
DOM manipulation, animations and a mini project (Accordion Menu).
The theme uses red and white colors.

## Pages

| Page            | Tasks                                                   |
| --------------- | ------------------------------------------------------- |
| index.html      | Task 0 (Setup), Task 1 (Selectors & CSS)                |
| effects.html    | Task 2 (show/hide), Task 3 (fade), Task 4 (slide)       |
| dom.html        | Task 5 (add/remove), Task 6 (attributes), Task 7 (form) |
| animations.html | Task 8 (basic), Task 9 (sequential), Task 10 (combined) |
| project.html    | Task 11 (Accordion Menu)                                |

## How to run

1. Clone the repository.
2. Open `index.html` in a browser (internet is needed for the jQuery CDN).
3. Open the console (F12) to see the "jQuery is ready!" message.
